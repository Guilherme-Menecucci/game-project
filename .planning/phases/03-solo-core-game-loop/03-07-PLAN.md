    Create apps/client/src/scenes/GameScene.ts:
    Extends Phaser.Scene. Key: 'GameScene'.
    Receives room (Colyseus Room) via scene data (this.scene.settings.data.room).

    Type imports: import type { Room } from '@colyseus/sdk'

    Coordinate helper (inline, not shared — avoids shared package dependency in scene):
    const toGU = (subUnits: number) => subUnits / 1000  (sub-units to game units for Phaser)

    Private fields:
    - room: Room (set from scene data in create())
    - playerSprites: Map of string to Phaser.GameObjects.Sprite
    - enemySprites: Map of string to Phaser.GameObjects.Sprite
    - gemSprites: Map of string to Phaser.GameObjects.Sprite
    - projectileSprites: Map of string to Phaser.GameObjects.Sprite
    - localPlayerId: string (from room.sessionId)
    - cursors: Phaser.Types.Input.Keyboard.CursorKeys
    - wasd: { up, down, left, right } keyboard keys
    - inputTimer: number (ms since last input send)
    - sendSeq: number = 0 (monotonically incrementing sequence per D-02)
    - INPUT_INTERVAL = 50  (50ms = 20Hz input rate, matches D-02)

    create(data):
    this.room = data.room
    this.localPlayerId = this.room.sessionId

    Set world bounds (4096 x 4096 game units):
    this.physics.world.setBounds(0, 0, 4096, 4096)
    this.cameras.main.setBounds(0, 0, 4096, 4096)
    this.cameras.main.setBackgroundColor('#1e2030')

    Set up cursor keys and WASD:
    this.cursors = this.input.keyboard!.createCursorKeys()
    this.wasd = {
      up: this.input.keyboard!.addKey(Phaser.Input.Keyboard.KeyCodes.W),
      down: this.input.keyboard!.addKey(Phaser.Input.Keyboard.KeyCodes.S),
      left: this.input.keyboard!.addKey(Phaser.Input.Keyboard.KeyCodes.A),
      right: this.input.keyboard!.addKey(Phaser.Input.Keyboard.KeyCodes.D),
    }

    Register Colyseus state change listeners for players, enemies, gems, projectiles.
    room.state.players.onAdd: create sprite at toGU(player.x), toGU(player.y) with frame 'player'; setDepth(2)
    room.state.players.onChange: update sprite position to toGU(player.x), toGU(player.y)
    room.state.players.onRemove: destroy sprite and remove from map

    room.state.enemies.onAdd: frame = enemy.archetype (matches atlas frame name); setDepth(1)
    room.state.enemies.onChange: update sprite position
    room.state.enemies.onRemove: destroy sprite; increment kill counter in registry

    room.state.gems.onAdd: frame 'gem'; setDepth(0)
    room.state.gems.onChange: update position
    room.state.gems.onRemove: destroy sprite

    room.state.projectiles.onAdd: select frame based on isEnemy flag (per GAME-05):
      const frame = projectile.isEnemy ? 'proj_enemy' : 'proj_player'
      Create sprite with selected frame; setDepth(3)
    room.state.projectiles.onChange: update position
    room.state.projectiles.onRemove: destroy sprite

    When local player sprite is created: start camera follow:
    this.cameras.main.startFollow(sprite, true, 0.1, 0.1)  (lerp 0.1 per axis)

    Game-over detection: when local player's hp <= 0 in room.state, or room.onLeave:
    this.game.events.emit('gameover', { killCount: this.game.registry.get('killCount') ?? 0 })

    Kill counter: maintained in game.registry. On enemy onRemove: increment registry killCount.
    Initialize registry killCount = 0 in create().

    update(_time: number, delta: number):
    Capture keyboard input — compute moveVector:
    let mx = 0, my = 0
    if left or A key is down: mx -= 1
    if right or D key is down: mx += 1
    if up or W key is down: my -= 1
    if down or S key is down: my += 1
    Normalize for diagonal: if mx !== 0 && my !== 0: mx *= 0.7071; my *= 0.7071

    Accumulate delta: this.inputTimer += delta
    If inputTimer >= INPUT_INTERVAL:
    Send input: this.room.send('input', { moveVector: { x: mx, y: my }, aimAngle: 0, actionFlags: 0, seq: this.sendSeq++, tick: 0 })
    Reset: this.inputTimer = 0

    IMPORTANT: The coordinate division by 1000 (toGU) is required because the server stores
    sub-unit integers (e.g., 2,000,000) but Phaser expects game units (e.g., 2000).
    Without this conversion, all entities render at positions 1000x off-screen.
