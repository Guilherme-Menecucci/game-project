**As a** player, **I want to** click "Solo Run" and immediately enter a playable horde survival loop, **so that** I experience the core game chaos with zero friction.

<objective>
Add weapons, collision, ranged enemy AI (keep-distance + projectile fire), enemy contact damage,
XP gems, and leveling to the shared game simulation — the full combat layer that makes the game loop
complete (GAME-03, GAME-05, GAME-06, GAME-07).

This plan runs in Wave 2, parallel with plan 03-04 (Colyseus server) and plan 03-05 (client shell).
Combat sim only depends on the shared package (plan 03-02). The Colyseus Room calls simulateTick —
adding combat logic to simulateTick.ts automatically propagates to the running server without changes
to SoloRoom.ts.

Ranged archetype AI (GAME-05): ranged enemies keep distance from the player. When distance to the
nearest player is less than KEEP_DISTANCE_INNER (120,000 sub-units / 120 game units), the ranged
enemy moves directly away from the player. When distance is greater than KEEP_DISTANCE_OUTER
(160,000 sub-units / 160 game units), it moves toward the player. Between inner and outer thresholds,
it holds position and fires. Every ENEMY_FIRE_INTERVAL_TICKS (20 ticks = 1 second at 20Hz) the ranged
enemy spawns a PlainProjectileState with isEnemy:true aimed at the nearest player. Enemy projectiles
damage the player on contact (same applyCollisions pass, isEnemy branch) and are removed on hit.

Enemy contact damage is REQUIRED for the game-over path to be reachable. Without it, player hp
never decreases and the GameOverScreen (plan 03-08) can never appear. This is not optional.

Also adds lastFireTick to PlainEnemyState in state.ts — this is plain-sim state only and is NOT
mirrored to GameSchema (plan 03-09 doesn't need a new schema field for it).

Output: 4 files in packages/shared/src/ adding the full combat layer + 1 test file
</objective>

    Export function autoFire(state: PlainGameState, prng: Prng): PlainGameState:

    vx = Math.round(Math.cos(angle) * PLAYER_PROJECTILE_SPEED)
    vy = Math.round(Math.sin(angle) * PLAYER_PROJECTILE_SPEED)

    Export function applyCollisions(state: PlainGameState): PlainGameState:
    Build a UniformGrid. Insert all enemies into grid.
    For each player projectile (isEnemy === false): queryRadius at projectile position with radius 8,000.
    For first hit enemy: decrement enemy.hp by projectile.damage.
    If enemy.hp <= 0: remove enemy; create GemState at enemy.x, enemy.y.

    For enemy projectiles (isEnemy === true): build a second grid with player positions.
    For each enemy projectile: queryRadius at projectile position with radius 8,000.
    For first hit player: player.hp = Math.max(0, player.hp - projectile.damage). Remove projectile.

    Return new state with updated enemies, gems, players, projectiles.

    Export function applyEnemyContactDamage(state: PlainGameState): PlainGameState:
    Build a UniformGrid. Insert all players into grid.
    For each enemy: queryRadius at enemy position with radius = ENEMY_CONTACT_RADIUS.
    For each player within radius: player.hp = Math.max(0, player.hp - ENEMY_CONTACT_DAMAGE).

    Return new state.
